# 🏎️ Formula 1 Race Intelligence Dashboard

**An interactive Tableau analytics project on Formula 1 driver performance, team strategy and championship trends, presented on a custom React website.**

---

## 📌 Project Overview

This project turns Formula 1 race data into an interactive Tableau Public dashboard and a guided data story, then presents both on a responsive website built with React, Vite and Tailwind CSS.

- **🌐 Live Site:** https://f1-race-dashboard-bunm.bolt.host
- **📊 Tableau Dashboard:** https://public.tableau.com/app/profile/rashi.khanvilkar/viz/ProjectF1_17935197172540/Story1

## ✨ Key Features

| Section | What it shows |
|:--|:--|
| **🏁 Global Driver Distribution** | Map of drivers across Grand Prix nations |
| **🔧 Driver Reliability Analysis** | DNF counts and reasons per driver |
| **🏆 Driver Performance Leaderboard** | Points and results by driver |
| **🏎️ Team Championship Performance** | Constructor ranking and team trends |
| **🛞 Tyre Compound Usage** | Distribution of soft, medium and hard tyres |
| **📖 Data Story** | A guided narrative through the main findings |

Filters on the dashboard let you slice results by season, DNF reason and Top N.
